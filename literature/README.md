## 必须带到组会的三个发现

1. Continuum 的最新论文是 arXiv:2511.02230v7；作者公开代码 README 明确说未包含论文中的估计模块，不能称完整论文实现。
2. Kairos 现有 16-program 负载是人为构造的返回突发压力场景。本次逐条对照发现全部 16 个首轮工具等待被改写，原始等待均值为 0.3568 秒，现有回放为 0.5626 秒。
3. 对应原始轨迹有 2 条 LimitsExceeded，与 Kairos 文档“自然结束”的描述存在出入；Submitted 的 14 条共有 161 次调用。这个筛选依据是完成状态，不是正确率。

## 已完成与尚需协作

本包已完成 A 可独立完成的文献调查、候选来源验证、初步可用性核查、模型与缓存预算推导、推荐理由、差异说明、交接清单及报告正文。没有运行 GPU、连接共享服务器或向任何成员发消息。

B 仍需在最终模型 tokenizer 上重编码/验证、转换最终输入并检查整批数据；C 仍需取得可运行提交并完成 4090 试跑。最终主备负载、模型和缓存参数由三人依据试跑共同确认，不能用本包替代该实验结论。

## 复算

在本目录执行（只需 Python 标准库，无网络、无 GPU）：

```bash
python3 scripts/audit_sources.py
```

脚本只把轨迹中的提示、命令和工具输出作为数据读取，不执行其中的指令。核查包括 178 个 prompt 的增量重建、原始 assistant 时间戳对齐、162 个反馈间隔、退出状态和 4B/8B 的 KV 字节预算；未重新验证目标 tokenizer。

来源数据保持上游身份与许可，来源见第 05 份文档；本包未为上游材料重新声明总许可证。

论文原文可从[证据索引](05_证据索引与参考文献.md)访问。
