# Replay 检查工具验证记录

日期：2026-11-02。环境：本地 Windows / Python；未连接服务器或运行 GPU。

## 自动测试

执行 `python -B -X utf8 -m unittest discover -s 人员C_接手材料/Replay检查工具 -p test_check_replay.py -v`，最终 18 个测试全部通过（部分测试包含多个错误输入子案例）。

覆盖：

- 正确的单轮及多轮前缀重建与签名匹配。
- 输入文件只读、报告生成及拒绝覆盖已有报告目录。
- 重复程序 ID、前驱不存在、自环及多节点依赖环。
- 布尔/负数/小数/非数组 token 输入、前缀越界、错误输入长度和输出预算。
- 上下文及词表范围、负等待、非有限 JSON 数值、必需来源字段缺失。
- 消息轮数、角色及完整协议缺失、null 协议。
- 消息文件/输入 token 哈希篡改、未来信息声明不合规。
- 缺失、多余、重复请求签名，以及损坏 JSON 和重复 JSON 键。
- 旧 trace 来源哈希单列警告；前轮输入损坏时不虚构后续重建结果。

这些测试验证工具能发现上述错误，不证明可以识别所有语义错误或所有数据规模下的行为。
